## leerdoel gebruik Laravel
**Specifiek**

> Tijdens mijn stage wil ik beter leren werken met Laravel. Aan het einde van mijn stage wil ik zelfstandig aan een Laravel-project kunnen werken en bestaande code kunnen begrijpen en aanpassen. Ook wil ik zelf nieuwe functionaliteiten kunnen maken. Mijn doel is om Laravel voldoende goed te leren dat ik een groot deel van wat ik later op school krijg al ken en kan toepassen.

**Meetbaar**

> Ik heb mijn doel bereikt als ik zelfstandig taken in Laravel kan uitvoeren zonder steeds hulp te hoeven vragen. Tijdens mijn stage wil ik minimaal drie functionaliteiten zelfstandig hebben gemaakt of aangepast. Ook kan ik aan mijn stagebegeleider en collega's vragen of zij vinden dat ik zelfstandiger ben geworden in het werken met Laravel.

**Acceptabel**

> Dit doel past goed bij mijn stage, omdat ik tijdens mijn werkzaamheden veel met Laravel werk. Het is ook nuttig voor mijn opleiding, omdat Laravel daar later nog behandeld wordt. De kennis die ik tijdens mijn stage opdoe kan ik dus zowel tijdens mijn stage als later op school gebruiken.

**Realistisch**

> Ik denk dat dit doel haalbaar is omdat ik tijdens mijn stage veel met Laravel werk. Hierdoor kan ik er bijna dagelijks mee oefenen. Als ik ergens niet uitkom kan ik hulp vragen aan collega's. Ook kan ik gebruikmaken van de Laravel-documentatie en andere informatie op internet.

**Tijdsgebonden**  
Hier zou ik gewoon de **begin- en einddatum van je stage** invullen.

## leerdoel gebruik GIT
**Specifiek**

> Tijdens mijn stage wil ik mijn kennis van Git verder uitbreiden. Ik ken de basis van Git al, maar wil vooral leren hoe Git wordt gebruikt om binnen een developmentteam samen aan een project te werken. Hierbij wil ik meer ervaring krijgen met branches, pull requests, merge conflicts en het oplossen van problemen die tijdens het werken met Git kunnen ontstaan.

**Meetbaar**

> Ik heb dit doel bereikt als ik Git goed kan gebruiken binnen de werkwijze van het developmentteam. Ik wil op de juiste manier met branches en pull requests kunnen werken, merge conflicts kunnen oplossen en weten hoe ik verschillende problemen met Git kan aanpakken.

**Acceptabel**

> Dit doel past goed bij mijn stage omdat Git dagelijks wordt gebruikt om samen aan projecten te werken. Als ik Git beter leer gebruiken, kan ik makkelijker samenwerken met mijn collega's en op de juiste manier mijn wijzigingen toevoegen aan een project.

**Realistisch**

> Ik denk dat dit doel haalbaar is omdat ik tijdens mijn stage regelmatig met Git werk. Hierdoor krijg ik genoeg kansen om ervaring op te doen met bijvoorbeeld pull requests, branches en merge conflicts. Wanneer ik een situatie nog niet ken, kan ik deze samen met een collega bekijken en ervan leren.

**Tijdsgebonden**

> Tijdens mijn hele stage ga ik mijn kennis van Git verder ontwikkelen. Aan het einde van mijn stage wil ik Git goed genoeg beheersen om zonder problemen mee te kunnen werken binnen de Git-workflow van een developmentteam.
