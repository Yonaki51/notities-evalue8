 Remaining things from the earlier checklist:

 1. Raw HTML output decision
    setupArticles contains rendered HTML. We left the templates/clickable using normal {{ }} for now because it seemed
    to render in the modal. Still worth testing the final sent email.

 2. Partial model access
    Your partial currently uses array-style access:

    ```blade
      $setup['name']
      $setup['articles']
      $article['article_number']
    ```

    Since real data is Eloquent models, object-style access would be more idiomatic:

    ```text
      setup name
      setup articles
      article article_number
    ```

 3. Email-safe styling
    The partial table is currently very plain. You may want to add email-friendly attributes/styles:
     - width
     - border
     - cellpadding
     - cellspacing
     - border-collapse
     - header alignment

 4. Translations / Dutch labels
    The partial currently says:
     - Setup name
     - article number
     - description
     - amount
     - no articles found
     - no setup found

    You may want Dutch labels, or translations.

 5. Final email test
    Test not just the modal, but the actual sent/generated email body.

     - Setups
     - Setup Articles
