## code help for if it disappears
 Got it. Let’s walk through the original code slowly.

 Original code:

 ```php
   $resetUrl = sprintf(
       config('evalue8.forgot_password_route'),
       request()->getScheme().'://'.$notifiable->whiteLabel->domain,
       $this->token,
       $notifiable->getEmailForPasswordReset(),
   );
 ```

 This creates one variable:

 ```php
   $resetUrl
 ```

 That variable is the password reset link.

 1. What is config(...)?

 This line:

 ```php
   config('evalue8.forgot_password_route')
 ```

 reads this value from config/evalue8.php:

 ```php
   '%s/change-password?token=%s&email=%s'
 ```

 That is a template.

 It means:

 ```text
   SOMETHING/change-password?token=SOMETHING&email=SOMETHING
 ```

 The %s parts are empty slots.

 2. What does sprintf(...) do?

 sprintf() fills those %s slots.

 Template:

 ```text
   %s/change-password?token=%s&email=%s
 ```

 Values:

 ```text
   1. http://core.evalue8.local
   2. reset token
   3. review+tag@example.org
 ```

 Result:

 ```text
   http://core.evalue8.local/change-password?token=TOKEN&email=review+tag@example.org
 ```

 So the original code gets the URL by taking a template and filling its blanks.

 4. Where does the domain come from?

 This part:

 ```php
   request()->getScheme().'://'.$notifiable->whiteLabel->domain
 ```

 builds:

 ```text
   http://core.evalue8.local
 ```

 Breakdown:

 ```php
   request()->getScheme()
 ```

 returns:

 ```text
   http
 ```

 Then:

 ```php
   .'://'.
 ```

 adds:

 ```text
   ://
 ```

 Then:

 ```php
   $notifiable->whiteLabel->domain
 ```

 returns the white-label domain, like:

 ```text
   core.evalue8.local
 ```

 Together:

 ```text
   http://core.evalue8.local
 ```

 5. Where does the token come from?

 This part:

 ```php
   $this->token
 ```

 comes from Laravel’s password reset system. It is the secret reset token.

 Example:

 ```text
   99c65488...
 ```

 6. Where does the email come from?

 This part:

 ```php
   $notifiable->getEmailForPasswordReset()
 ```

 returns the user’s email.

 Example:

 ```text
   review+tag@example.org
 ```

 Here, $notifiable means “the user receiving this notification”.

 7. What did we change?

 Instead of using one big template with token and email inside it, we split the URL into two parts.

 ### New part 1: base URL

 ```php
   $baseUrl = request()->getScheme().'://'.$notifiable->whiteLabel->domain.'/change-password';
 ```

 This creates:

 ```text
   http://core.evalue8.local/change-password
 ```

 No token. No email. Just the page URL.

 ### New part 2: query string

 ```php
   $query = http_build_query([
       'token' => $this->token,
       'email' => $notifiable->getEmailForPasswordReset(),
   ]);
 ```

 This creates the part after ?:

 ```text
   token=TOKEN&email=review%2Btag%40example.org
 ```

 It safely encodes the values.

 ### New part 3: final URL

 ```php
   $resetUrl = $baseUrl.'?'.$query;
 ```

 This joins them:

 ```text
   http://core.evalue8.local/change-password?token=TOKEN&email=review%2Btag%40example.org
 ```

 Big difference

 Old code:

 ```text
   template with raw email pasted in
 ```

 New code:

 ```text
   base URL + safely encoded query values
 ```

 That is the fix.
